# CLASSHUB V2.1 — CLEAN MOBILE-FIRST BUILD

Upload ONLY these 3 files to the root of the APATWEB repository:
- index.html
- style.css
- app.js

Important: replace/delete old HTML/CSS/JS files first so old markup cannot mix with this build.

V2.1 is rebuilt mobile-first. `#main` has no desktop left margin on screens <=760px, the sidebar becomes an off-canvas drawer, and horizontal overflow is explicitly prevented.

The project uses demo data for 36 students, Monday-Friday schedules, announcements, and duty rosters (7 Mon-Thu, 6 Fri).
